# \# Görev Listem – React TODO Uygulaması

# 

# React ve Pure CSS ile geliştirilmiş basit bir görev yönetim uygulamasıdır. Görevler tarayıcının LocalStorage alanında saklanır, sayfa yenilense de kaybolmaz.

# 

# !\[Uygulama ekran görüntüsü](screenshots/screenshot.png)

# 

# \## Özellikler

# 

# \- Görev ekleme

# \- Görevleri listeleme

# \- Görev güncelleme (başlığı düzenleme ve tamamlandı olarak işaretleme)

# \- Görev silme

# \- Verilerin LocalStorage ile kalıcı saklanması

# 

# \## Kullanılan Teknolojiler

# 

# \- React (Vite ile kuruldu)

# \- Pure CSS

# \- LocalStorage

# 

# \## Kurulum

# 

# 1\. Projeyi indirin:

# 

# ```

# git clone <repo-adresi>

# cd <proje-klasörü>

# ```

# 

# 2\. Bağımlılıkları kurun:

# 

# ```

# npm install

# ```

# 

# 3\. Uygulamayı başlatın:

# 

# ```

# npm run dev

# ```

# 

# 4\. Tarayıcıda terminalde yazan adresi açın (genellikle `http://localhost:5173`).

# 

# \## Klasör Yapısı

# 

# ```

# src/

# ├── components/   → TaskForm, TaskItem

# ├── pages/        → Home

# ├── interfaces/   → Görev modeli (taskModel.js)

# ├── App.jsx

# ├── App.css

# └── index.css

# ```
